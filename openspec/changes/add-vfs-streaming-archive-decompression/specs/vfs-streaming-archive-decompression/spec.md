# Spec Delta

## Purpose

VFS 为游戏提供归档目录和按需成员读取，使浏览器可以挂载本地或可按范围读取的 ZIP、7z 和 RAR 包，从中读取选定成员并复用原有运行时接口。

## ADDED Requirements

### Requirement: 通过 VFS 按范围挂载归档

VFS MUST 挂载本地 File/Blob 与可按字节范围读取的网络 GameSource，识别 ZIP（包括 Zip64）、7z、RAR4 和 RAR5。打开归档 MUST 按格式读取所需头部与索引区间。游戏库 MUST 通过现有来源打开和恢复挂载，并按原有路径暴露归档文件及其成员。运行时写入 MUST 进入本地覆层。

#### Scenario: 用浏览器打开本地或远程归档
- **GIVEN** 一个具有可分离索引和成员数据的大归档
- **WHEN** 用户打开来源并列出归档成员
- **THEN** 游戏库通过 VFS 返回成员目录
- **AND** 读取记录只包含格式探测和索引所需的输入范围

#### Scenario: 网络来源无法提供准确范围
- **WHEN** 网络来源忽略 Range、缺少浏览器所需的 CORS 数据、返回无效范围或读取过程中检测到归档版本改变
- **THEN** 挂载或读取报告范围能力错误或来源失效
- **AND** 累计传输受配置的字节预算限制

### Requirement: 提供成员流和解压后区间读取

VFS MUST 提供可取消、有背压的成员 ReadableStream，以及以解压后偏移量访问成员范围的接口。可直接映射的成员 MUST 只读取映射区间及必要的元数据。需要顺序解码的成员 MUST 从适用的解码起点产生所请求的范围，并记录适用的解码工作量限制。既有整文件接口 MUST 继续支持预算内的读取，完整性结果 MUST 反映实际覆盖的字节。

#### Scenario: 读取未加密 STORED 成员中的一段
- **WHEN** 调用者请求一个 STORED 成员的非零偏移区间
- **THEN** VFS 返回与原文件该区间一致的字节
- **AND** 输入记录只包含定位元数据和所需的成员字节

#### Scenario: 读取顺序解码的压缩成员
- **WHEN** 调用者读取一个普通压缩成员的流，或请求一个 solid 成员的中间区间
- **THEN** VFS 从该格式允许的起点解码并返回目标字节
- **AND** 在允许的预算内，流先输出可用数据块，再完成整个成员
- **AND** 其余成员及前置字节的解码输出不进入结果缓冲

### Requirement: 处理受限资源和归档错误

归档读取 MUST 限制索引、输入、解码工作内存与工作量、在途输出及整文件缓冲。取消、关页、解码失败或达到限制时 MUST 释放相关网络请求和解码资源。VFS MUST 拒绝越界和歧义成员路径，并报告不支持的格式变体、错误凭据与损坏数据。支持的加密 ZIP MUST 使用本次读取提供的密码。

#### Scenario: 慢速消费者取消流
- **WHEN** 消费者读取一个大成员、减慢消费速度并取消
- **THEN** 在途解码数据受背压限制
- **AND** 取消结束本次读取并释放相关资源

#### Scenario: 加密或异常归档
- **WHEN** 支持的加密 ZIP 使用正确密码打开
- **THEN** 返回正确成员字节
- **AND** 缺少密码、错误密码、损坏或超限输入各有可区分的结果
- **AND** 危险路径和链接不会生成可访问的 VFS 成员

### Requirement: 用浏览器证据确认格式能力

项目 MUST 在真实浏览器中分别验证 ZIP/Zip64、7z、RAR4 和 RAR5 的本地与网络挂载。启用的每种来源与格式组合 MUST 通过读取正确性、首块输出、取消和资源预算的验证。项目 MUST 记录格式及变体的支持情况、对应上游源码版本、构建方法和分发许可。

#### Scenario: 核对各格式的浏览器验收结果
- **WHEN** 实现者在浏览器中运行普通成员、solid 成员、Zip64、加密 ZIP 和拒绝 Range 的夹具
- **THEN** 记录校验字节、实际请求范围、解码起点、首块输出与缓冲峰值
- **AND** 发布的支持矩阵与各组合的实测结果一致
