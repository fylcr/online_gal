# The patches the minimal platform port is built from. One file name per line, in application
# order; `#` starts a comment and blank lines are ignored. Paths are relative to `patches/`.
#
# This list is the explicit interface between the recipes and the source gate. The recipes spell the
# same names in their `for p in ...` loops, `make-source-bundle.mjs` carries each one as an entry,
# and `scripts/check-sources.mjs` requires that all three agree with this file in BOTH directions:
# a patch named here and missing, and a patch present in `patches/` and named here by neither this
# file nor a declaration, are both failures. The guard reads this file rather than the recipe's loop,
# so the table it enforces is not derived from the thing it is supposed to constrain.
#
# 0001  ReadAt host source hook. The host supplies the byte range the engine reads; without the hook
#       the web build has no way to serve the archive it was handed.
# 0002  numeric strto exceptions. Upstream still calls unguarded `std::strtod`/`std::strtof` on
#       script-supplied values, which throws out of the engine on a malformed number.
# 0003  lytween loopdelay. The pin never reads the wait between repeats, so a
#       repeating tween restarts at once. `0003-scene-checkpoint.patch` is a
#       different, retired save/restore feature and is not this file.
0001-pf8-readat-host-source.patch
0002-numeric-strto.patch
0003-tween-loopdelay.patch
# Default-off shared Lua animation/CG dispatch observation; no animation changes.
0004-animation-dispatch-observe.patch
